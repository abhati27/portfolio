## 🐛 Troubleshooting

### Site shows 404
- Make sure you selected "GitHub Actions" in Settings → Pages
- Wait for deployment to complete (check Actions tab)
- Try https://abhati27.github.io/portfolio/ with trailing slash

### Old site still showing
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
- Clear browser cache
- Try incognito/private window

### Deployment failing
- Check Actions tab for error logs
- Verify workflow file exists: `.github/workflows/deploy.yml`
- Make sure repository is public (or you have GitHub Pro for private repos)
